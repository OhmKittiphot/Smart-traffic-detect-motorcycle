# CCTV Admin Dashboard (Django)

เว็บสำหรับผู้ดูแลระบบ ใช้ดูภาพจากกล้องหรือไฟล์วิดีโอพร้อมผลตรวจจับ และดูรายการรถที่ขับผ่าน
แถวสีเขียวคือรถปกติ แถวสีแดงคือรถที่ทำผิดกฎ ได้แก่ ไม่สวมหมวกกันน็อก, ซ้อนเกิน `max_riders` คน และขับเร็วเกิน `speed_limit_kmh`

## เริ่มใช้งาน

ใช้ Python จาก venv ของโปรเจกต์ (`venv\`) เสมอ รันจากโฟลเดอร์รากของโปรเจกต์:

```bash
venv\Scripts\python -m pip install -r requirements.txt
venv\Scripts\python web\manage.py createsuperuser
venv\Scripts\python web\run.py
```

เปิด http://127.0.0.1:8000 แล้วเข้าสู่ระบบด้วยบัญชีที่สร้างไว้ ตอนเปิดเว็บครั้งแรก ระบบจะใช้เวลาโหลดโมเดลประมาณ 10–30 วินาที

- **กล้องสด**: ใช้ `RTSP_URL` จาก `.env` ถ้าไม่ได้ตั้งค่าไว้ หรือกล้องไม่ส่งภาพเกิน 5 วินาที หน้าจอจะแสดง **NO SIGNAL**
- **กล้อง CCTV มูลนิธิ iTIC (ส่วนเสริม)**: เมื่อเลือกกล้องสด จะมี dropdown ให้เลือกระหว่าง IP camera กับกล้อง iTIC ฉะเชิงเทรา (ccs06) ส่วนเสริมนี้อยู่ใน `web/dashboard/itic_cameras.py` ถ้าลบไฟล์นี้ dropdown จะหายไป และระบบจะกลับไปใช้ IP camera
- **ไฟล์วิดีโอ**: เลือกได้เฉพาะไฟล์ที่อยู่ในโฟลเดอร์ `input/`
- **ภาพหลักฐาน**: กดรูปเล็กในตาราง เพื่อดูภาพรถและคนขี่ตอนที่รถอยู่ใกล้กล้องที่สุด
- **จัดการผู้ใช้และดูประวัติ**: ไปที่ `/admin/` เพื่อเพิ่มหรือลบผู้ดูแล ดูบันทึกว่าใครเปลี่ยนแหล่งวิดีโอ และลบรายการรถ
- **API ภายใน**: หน้า dashboard คุยกับ server ผ่าน `/api/...` ซึ่งเขียนด้วย Django REST Framework แบบ `APIView` + `Serializer` (`dashboard/views.py` และ `dashboard/serializers.py`) ใช้ได้เฉพาะจากหน้า dashboard ที่ล็อกอินแล้ว

## ความปลอดภัย

- ทุกหน้าต้องเข้าสู่ระบบ และใช้ได้เฉพาะบัญชี staff/superuser เท่านั้น
- ถ้าใส่รหัสผ่านผิด 5 ครั้ง บัญชีนั้นจาก IP นั้นจะถูกล็อก 15 นาที (django-axes)
- session มีอายุสูงสุด 8 ชั่วโมงและหมดอายุเมื่อปิดเบราว์เซอร์ คุกกี้ตั้งเป็น HttpOnly และ SameSite=Strict
- มี CSRF ป้องกันทุกคำสั่ง POST และตั้ง CSP แบบเข้มงวด (ไม่มี inline script และไม่โหลดอะไรจากโดเมนอื่น)
- ภาพหลักฐานส่งผ่าน view ที่ต้องล็อกอินเท่านั้น ไม่มี URL สาธารณะ
- ไม่ส่ง URL ของกล้อง (ซึ่งมีรหัสผ่าน) ไปที่เบราว์เซอร์ และไม่พิมพ์ลง log
- server ฟังเฉพาะ `127.0.0.1` เป็นค่าเริ่มต้น

ตัวแปรเพิ่มเติมใน `.env` (ไม่ต้องตั้งก็ได้):

| ตัวแปร | ความหมาย |
|---|---|
| `DASHBOARD_HOST` / `DASHBOARD_PORT` | ค่าเริ่มต้นคือ `127.0.0.1` / `8000` ถ้าตั้งเป็น `0.0.0.0` คนอื่นในเครือข่ายจะเข้าได้ |
| `DJANGO_ALLOWED_HOSTS` | ชื่อโฮสต์หรือ IP ที่อนุญาต คั่นด้วย `,` ต้องตั้งเมื่อเปิดให้เครื่องอื่นเข้า |
| `DJANGO_HTTPS=1` | เปิด secure cookies, HSTS และ redirect ไป HTTPS (ใช้เมื่อมี HTTPS แล้ว) |
| `DJANGO_BEHIND_PROXY=1` | ใช้เมื่ออยู่หลัง reverse proxy เพื่อให้เชื่อ header `X-Forwarded-*` |
| `DJANGO_SECRET_KEY` | ถ้าไม่ตั้ง ระบบจะสร้างให้อัตโนมัติและเก็บไว้ที่ `web/.secret_key` |

ถ้าจะเปิดให้เครื่องอื่นในเครือข่ายเข้าใช้ ควรวางไว้หลัง reverse proxy ที่มี HTTPS (เช่น Caddy หรือ nginx) แล้วตั้ง `DJANGO_HTTPS=1`
